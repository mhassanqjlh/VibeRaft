# VibeRaft

VibeRaft is a Distributed Real-time System leveraging a scalable engine and auto-scaling architecture.

VibeRaft is built to be simple and practical, focusing on doing one thing well.

**Why VibeRaft?**

- VibeRaft is a Distributed Real-time
- System leveraging a scalable engine
- and auto-scaling architecture

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/VibeRaft.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
